# Power BI Sales Dashboard

**Question:** How can a manager see sales performance in 1 page?

**Tools:** Power BI Desktop, DAX

**Data:** Same Retail Sales data from Project 2

## Dashboard Shows

1.  **KPI Cards:** Total Revenue, Total Orders, Avg Order Value
2.  **Bar Chart:** Revenue by Product - Electronics leads
3.  **Map / Bar:** Revenue by Region - Nairobi leads
4.  **Line Chart:** Revenue by Month - Dec peak

## Insight

Managers can filter by Region / Product in 1 click. No need to read Excel.
Stock Electronics in Nairobi in Nov-Dec.
